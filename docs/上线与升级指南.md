# 上线与升级指南

## 一、小程序上线（个人主体，0–30 元/年）

### 1. 注册
1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 小程序 → 选「个人主体」。
2. 邮箱激活 + 身份证实名。个人主体注册**免费**；如需微信认证为 30 元/年（个人不认证也能发布，仅部分接口受限）。

### 2. 填写信息（过审关键）
- **名称**：避开「佛 / 寺 / 功德箱」等宗教类目词，推荐「静心日课」「清心功课」。
- **类目**：个人主体可选类目有限，建议「工具 > 效率」或「教育 > 学习教育」，与"自修工具"定位一致。
- **简介**：写"念佛计数、经文阅读、传统文化学习工具"，不出现募捐、收款字样。

### 3. 发布
1. 微信开发者工具导入 `miniprogram/`，`project.config.json` 的 `appid` 换成你的；
2. 真机预览确认 5 个页面正常 → 上传 → 版本管理里填版本号与备注；
3. mp 后台提交审核（首次 1–3 天），通过后手动「发布」。
4. 体验版可长期先用：审核期间可把体验版二维码发给朋友试用。

### 4. 现阶段的合规姿态（方案A）
- 不内嵌任何收款功能，功德箱仅"复制官方公益平台链接 / 跳转"；
- 页面文案已统一为「不代收善款，随喜经官方公益平台直达项目方」；
- 个人主体小程序**技术上也开不了微信支付**，双重保险。

## 二、网站部署（0 元/年）

静态站，无后端、无构建，两种免费方案任选：

### 方案1：Cloudflare Pages（推荐，国内访问相对稳）
1. 注册 [pages.cloudflare.com](https://pages.cloudflare.com) → Create a project → Direct Upload；
2. 上传 `website/` 整个目录（或先推到 GitHub 再连仓库）；
3. 自动获得 `xxx.pages.dev` 域名，可绑定自己的域名。

### 方案2：GitHub Pages
1. 新建仓库，把 `website/` 内容推上去（或单独 repo）；
2. Settings → Pages → 选分支 main / root；
3. 获得 `用户名.github.io/仓库名` 地址（国内偶有波动）。

> 想要国内快、可备案：加买域名（约 60 元/年）+ 国内轻量服务器（新用户约 100 元/年），备案后部署，即「方案B」约 150 元/年的水平。

## 三、后续升级自收款（方案C 清单）

钱不是问题，**资质和主体**才是，按顺序办：

1. **主体**：成立宗教活动场所（寺观教堂）或与已登记寺庙合作；个人/普通公司拿不到宗教类目资格。
2. **许可证**：向省宗教事务部门申请《互联网宗教信息服务许可证》。
3. **小程序认证**：以组织主体重新注册/迁移，微信认证 300 元/年；类目选「宗教」需上传许可证。
4. **微信支付**：用组织主体开商户号，配置 JSAPI 支付；公益/宗教类可咨询腾讯低费率。
5. **后端**：按 [收款接口契约.md](收款接口契约.md) 实现下单/查询接口（任何一台国内云服务器 + 域名即可）。
6. **切换**：`config/donation.js` 与 `website/js/config.js` 中
   - `mode` 改为 `'self'`
   - `apiBase` 填后端地址
   - 前端不用再动，功德箱自动变成「选金额 → 微信支付」。

## 四、二期功能建议（按人气优先级）

1. 回向墙云同步（storage.js 已预留接入点）→ 共修氛围是留存核心；
2. 课诵提醒（订阅消息）、连续功课打卡天数；
3. 大悲咒等逐句跟诵（音频由你自己录制后放 `data/`）；
4. 经文扩充（阿弥陀经、普门品等）。
