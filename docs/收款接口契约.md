# 自收款后端 · 接口契约（v1）

前端（小程序 / 网站）已按此契约写好调用代码，后端照此实现即可，联调时前端零改动。

## 通用约定

- Base URL：`config/donation.js → self.apiBase`（如 `https://api.example.com`）
- 格式：JSON（`Content-Type: application/json`）
- 金额：**单位为分**（`amount: 100 = 1 元`），后端必须校验在合理区间（如 1 分 – 5 万元）
- 幂等：同一用户短时间重复下单要能防重；支付回调必须幂等（同一订单只入账一次）
- 安全：全部走 HTTPS；回调验签（微信支付平台证书）；不在响应里暴露商户敏感信息

## 1. 创建订单（小程序调起 wx.requestPayment）

```
POST /api/donation/orders
{ "amount": 6600, "channel": "wechat_pay", "message": "" }
```

响应 200：

```json
{
  "orderId": "20260913xxxx",
  "payParams": {
    "timeStamp": "1757700000",
    "nonceStr": "xxxx",
    "package": "prepay_id=wx26xxxxxxxx",
    "signType": "RSA",
    "paySign": "xxxx"
  }
}
```

小程序端对应代码：`components/donation-sheet/donation-sheet.js → paySelf()`，
拿到 `payParams` 直接传给 `wx.requestPayment`。

## 2. 查询订单状态

```
GET /api/donation/orders/{orderId}
```

响应：`{ "status": "pending" | "paid" | "failed", "amount": 6600 }`

## 3. 支付结果回调（微信支付 → 后端，前端不感知）

- 接收微信支付 `notify` 通知，验签后更新订单为 `paid`；
- 需要开捐赠票据时，在此落库用户信息获取入口（二期）。

## 4. 网站端支付（H5 / Native）

```
POST /api/donation/orders
{ "amount": 6600, "channel": "wechat_pay_h5" }
```

响应：`{ "payUrl": "https://..." }`（网站端代码已按 `payUrl` 跳转实现，见 `website/js/app.js`）

## 5. 回向墙云同步（二期，可选）

```
GET  /api/wall?cursor=0&limit=20     → { "items": [ ... ] }
POST /api/wall                       → { "id": "..." }   // 内容审核后上架
```

前端接入点：小程序 `utils/storage.js`（getWall/addWall 处加云端读写）、网站 `js/app.js` 的 wall 段。
